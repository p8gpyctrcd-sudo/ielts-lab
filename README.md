# IELTS LAB

雅思听力、阅读机考练习网站，静态 HTML、CSS 与 JavaScript，可部署到 GitHub Pages。

## 网站功能

- 剑雅 9–21，共 104 套听力及 A 类阅读，4,160 个答题位置。
- 在线填空与选择、自动批阅、文字原文对照、计时与练习记录。
- 每个听力 Part 独立选择录音，录音保存在当前浏览器。
- 手机先加载轻量题库目录，进入试卷时按需下载题目，加载失败可重试。

## 部署

网站文件位于 `dist/`，`.github/workflows/pages.yml` 会在推送 `main` 后自动发布。
首次部署需在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

## 数据保存

音频与作答使用浏览器本地存储，不会上传到 GitHub，也不会跨设备同步。
从本地网站切换到 GitHub Pages 后属于不同网站地址，需在新网址重新选择录音。

## 内容状态

部分扫描文字及复杂表格仍可能存在识别、排版误差，可通过“原题对照”核实。
剑雅 20 的现有资料缺少听力原文，可逐 Part 手动导入；Test 3 阅读第 27 题答案待核对。
剑雅 12 保留原书 Test 5–8 编号。
